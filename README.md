# Login Analyzer

A simple Python-based login analyzer that tracks failed login attempts and detects suspicious activity, including possible brute-force attacks.

## Features

- Takes a username as input
- Allows the user to define the maximum number of login attempts to check
- Tracks failed login attempts
- Displays a warning after 3 failed attempts
- Detects a possible brute-force attack after 5 failed attempts
- Stops monitoring when a login is successful

## Technologies Used

- Python
- Git
- GitHub
